# GCG Prime - Site Vitrine

## Contexte

GCG Prime est une EURL spécialisée dans le développement logiciel et le conseil informatique.

L'activité principale est l'accompagnement d'entreprises sur des projets backend, architecture logicielle, APIs, cloud et modernisation d'applications.

Le site a pour objectif :

- Présenter l'entreprise
- Présenter les services proposés
- Renforcer la crédibilité de la société
- Faciliter la prise de contact
- Servir de support commercial lors de prospection

Le site n'est pas une application métier.

C'est un site vitrine statique ultra rapide, moderne et professionnel.

## Consignes pour Codex

Lorsque tu proposes du code :

- privilégier la simplicité
- éviter toute dépendance inutile
- privilégier l'accessibilité
- privilégier les performances
- commenter le minimum nécessaire
- utiliser des composants réutilisables
- respecter le design system défini ci-dessus

Chaque nouvelle fonctionnalité doit rester cohérente avec l'objectif principal : générer de la confiance et faciliter la prise de contact.
